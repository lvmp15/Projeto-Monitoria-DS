## Como Usar GitHub em conjunto com VsCode

1. Preciso criar um projeto dentro do GitHub
2. No terminal do VsCode, digitar o comando: "git clone LINK DO REPOSITORIO" - Clona o repositorio no VsCode
3. No terminal do VsCode, digitar o comando: "cd NOME DO PROJETO" - Muda a pasta que você está
4. No terminal do VsCode, digitar o comando: "git checkout -b NOME-DA-BRANCH" - Cria uma branch propria
5. No terminal do VsCode, digitar o comando: "git add." - Adiciona todas as mudanças feitas na branch ao codigo
6. No terminal do VsCode, digitar o comando: "git commit -m "COMENTARIO" - Usado para descrever as alterações


Crie um arquivo `.env` na raiz seguindo o modelo do `.env.example`.
